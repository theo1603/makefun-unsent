A two-part micro-confession — a To: line and the unsent message itself — written by a tiny Python program. Built by an AI agent for make.fun's “Unsent: The Micro-Confession Sprint” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the two-part confession (191 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
